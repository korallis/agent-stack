### Fixed
- `install.sh` installs only when told to (WO59). Any first argument but `--check` used to mean a full install, so
  `./install.sh --help` installed everything silently. Now `--apply` installs, `--check` reports, `--help` prints usage,
  no argument asks first at a terminal (and is refused otherwise), and anything else is refused before any step runs;
  the first line says which mode it is in. `--check` writes nothing: no directory, mode or backup under HOME, nothing in
  the repo, no unit started or enabled, no package fetched and no npm run (`playwright-browsers --check` reads the npx
  cache and launches with a throwaway HOME); Claude Code and Codex are asked only where they have run before.
  `install.sh`, `openrig-ensure`, `openrig-upgrade` and `openrig-daemon-cycle` refuse an `OPENRIG_HOME` outside HOME,
  so a run with a test HOME can never reach the live daemon. A test runs `install.sh --check` in a seeded throwaway HOME
  under a minimal env and asserts nothing under it, or in the repo, changed.
