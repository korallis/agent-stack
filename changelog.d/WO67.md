### Fixed
- Proof screenshots now reach the owner's Slack thread (WO67). OpenRig 0.6.3 asked Slack for an upload URL with a JSON
  body, which Slack rejects (`invalid_arguments`), so an update row's `--evidence-ref` image delivered as text only.
  New patch 141 sends both upload calls form-encoded and also attaches video (`.mp4`, `.webm`, `.mov`) and PDF, up
  to 50 MiB; a file that can't be sent is logged, and the text still lands.

### Added
- `openrig-slack-upload-check`: shows whether the installed daemon can upload to Slack, and with `--live` uploads a
  test image to the configured channel. The bot token is read by name, never printed.
- CULTURE: how to attach visual proof for the owner (`--evidence-ref <absolute path>`, Playwright screenshot and
  video recipes, files outside repos and `/tmp`, no secrets or real client data on screen).
