### Changed
- Local OpenRig patch 132 (project-qualified proof scopes) follows the upstream review of mvschwarz/openrig#136: a Windows
  absolute scope is never read as `<project>:<scope>`; catalog-project reads report their source watcher as unavailable and
  name the project; `rig proof judge` pins the project root its read resolved, and the daemon refuses with 409
  `project_changed` if the catalog moved it. Patch 137 is regenerated after it (same change, new offsets). Applied at the
  next `openrig-upgrade`.
- OpenRig patch 132 also carries #136's CodeRabbit fix (CWE-22): a proof judgment in a catalog project is bounded by that
  project's own root (evidence containment, `proofPolicy` search, recorded scope), not by the nearest `project.yaml`, which
  for a README-only project is an ancestor's. Before, an authorised judge could cite a sibling project's file as evidence.
