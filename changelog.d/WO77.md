### Fixed
- `agent-project-check` reads the queue again on large queues (WO77). It asked for every body of every rig in one
  request (`rig queue list -A -a --full`), which timed out against the CLI's 5-second limit at ~11,000 rows; the queue
  section then only warned. It now reads the list without bodies and fetches bodies per row over the daemon's API
  where a check needs them: each wave-map row, and the newest 100 recent rows for the `worktree_path=` check (4 at a
  time; the detail says what was sampled). A wave-map body that can't be read is named.
