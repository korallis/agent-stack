### Fixed
- `agent-heavy` bounds memory for all heavy runs together, not only per run (WO58). The per-run ceilings (2 builds at
  16G and 2 browser runs at 8G) could add up to most of the host, which also carries every seat, and on 2026-10-01 the
  host ran out of memory. Each run now has a ceiling with no swap (build 14G, browser 8G), and every run sits in
  `agent-heavy.slice`, capped at 24G together (`AGENT_HEAVY_TOTAL_MEM`). A run over a ceiling is OOM-killed inside its
  own scope and exits 137 with a message saying how to rerun it focused. The job's env sets worker hints (pytest
  `-n auto`, Vitest) to 4. Scopes are cleared after every run. Without a systemd user session it warns and runs the job
  unconfined.
