### Fixed
- The credential guard keeps Playwright MCP network and console listings out of transcripts (WO57). Their output
  carries tokens minted at runtime (session JWTs, `?token=`, signed URLs), which `--secrets` doesn't mask.
  `browser_network_requests`, `browser_network_request` and `browser_console_messages` now run only with their
  `filename` in the seat's scratch dir (`~/.local/state/agent-stack/playwright-mcp/net/<seat>/`, protected like a
  credential file) and named by what they write (`requests-`, `request-`, `part-`, `console-`), in Claude Code and
  Codex alike. The new `agent-net-summary <file>` prints method, host, path and status only, reading a file by the
  kind its name gives; raw header/body parts print only a count. The MCP runs with `--output-dir ~/.local/state/agent-stack/playwright-mcp`; run `./install.sh --apply`, then
  relaunch seats that use the browser.
