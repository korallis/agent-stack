### Changed
- The seat rules say where temporary scratch goes (WO60): `TMPDIR` and temp files on disk, outside any git repo, in
  `$HOME/.cache/<rig>-tmp/<seat>`, created and cleaned in a `trap`; never `/tmp`, a RAM disk on these hosts, and never
  inside a worktree, where tests take a directory under a git repo for a checkout. Review and QA checkouts still go
  under `~/Projects/<P>.worktrees/`.
