### Changed
- The seat rules say where temporary scratch goes (WO60): `TMPDIR` and temp files on disk, outside any git repo, in each
  job's own `mktemp -d` directory under the seat root `$HOME/.cache/<rig>-tmp/<seat>`, removed by that job's `trap`
  (never the shared root, which other jobs may be using); never `/tmp`, a RAM disk on these hosts, and never inside a
  worktree, where tests take a directory under a git repo for a checkout. CULTURE.md has a runnable example. Review and QA checkouts still go
  under `~/Projects/<P>.worktrees/`.
